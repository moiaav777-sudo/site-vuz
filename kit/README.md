# Комплект для аудита сайта вуза

1. Заполните раздел 0 в `03-zadanie-audit-saita-vuza.md` (сайт, вуз, учредитель, домены, разрешения).
2. Передайте исполнителю всю папку целиком.
3. Исполнитель производит `data.json`, снимок и скриншоты, затем:
   `python3 validate.py data.json --shots-dir shots/` (нужно «ОШИБОК: 0»)
   `python3 render.py data.json out/` (получается `out/index.html`)
4. Для пререндера без JavaScript нужны Python-пакет playwright и Chromium; без них рендер соберёт обычную версию и напишет об этом.

Образец данных: `data.example.json` (реальный аудит, скриншоты в образце не приложены, поэтому валидатор по нему запускается с флагом `--allow-missing-screenshots`).
