# site-vuz

Система аналитики и мониторинга официального сайта вуза: соответствие законодательству (ст. 29 ФЗ-273, ПП №1802, приказ Рособрнадзора №1493), доступность (ПП №102), персональные данные, безопасность периметра, целостность данных.

## Документы
- `docs/01-razbor-otcheta-v2.md` — разбор и проверка отчёта «панель руководителя» v2 (ПГУ, 30.09.2026).
- `docs/02-model-sistemy-proverki.md` — модель системы: фронты проверки, архитектура, роль LLM, скоринг, план внедрения.
- `rules/checks.yaml` — стартовый реестр проверок (норма → проверка → класс результата).
