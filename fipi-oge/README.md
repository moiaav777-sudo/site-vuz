# Материалы ОГЭ с сайта ФИПИ

Выгрузка официальных материалов ФГБНУ «ФИПИ» (Федеральный институт педагогических измерений) по основному государственному экзамену (ОГЭ, 9 класс).

Дата выгрузки: 2 октября 2026 г.

## Состав

### `demo/<год>/<предмет>/` — демоверсии, спецификации, кодификаторы

Источник: https://fipi.ru/oge/demoversii-specifikacii-kodifikatory (файлы лежат на doc.fipi.ru).

- `2027/` — проекты КИМ ОГЭ 2027 года (опубликованы в августе 2026, до утверждения помечены «ПРОЕКТ»).
- `2026/` — утверждённые КИМ ОГЭ 2026 года.

В каждой папке предмета три PDF (`_ДЕМО` — демонстрационный вариант с заданиями, ответами и критериями; `_СПЕЦ` — спецификация; `_КОДИФ` — кодификатор) и их текстовый слой `.txt`, снятый `pdftotext`. Текст формул в `.txt` искажён, для математики, физики, химии и информатики опирайтесь на PDF. Для русского языка дополнительно лежат материалы итогового собеседования.

В корне года: `Izmeneniya_KIM_OGE_2026.pdf` и `Plan_izmeneniya_KIM_OGE_2027.pdf` — официальные справки об изменениях КИМ.

Коды предметов: `ru` русский язык, `ma` математика, `fi` физика, `hi` химия, `inf` информатика, `bi` биология, `is` история, `gg` география, `ob` обществознание, `li` литература, `aya` английский, `nya` немецкий, `fya` французский, `iya` испанский. Для иностранных языков `_ДЕМО_ПЧ` — письменная часть, `_ДЕМО_УЧ` — устная часть.

Не включены в репозиторий (слишком большие, скачиваются скриптом `tools/download_demos.sh`): аудиозаписи к разделу «Аудирование» иностранных языков и папка «Доп. файлы» к информатике (исходные файлы для заданий 11–15, около 120 МБ).

### `bank/` — открытый банк заданий ОГЭ

Источник: https://oge.fipi.ru/bank/ (14 предметов). Банк отдаёт задания порциями через `questions.php`; выгружены все страницы (253 страницы по 100 заданий) и разобраны в JSON. Число заданий по каждому предмету совпадает со счётчиком «Кол-во заданий» на сайте.

Файлы:

- `bank/<код>.json` — задания одного предмета. Структура:
  - `documents` — общие тексты к группам заданий («Прочитайте текст и выполните задания»): `id`, `hint`, `html`, `text`, `images`, `files`.
  - `tasks` — задания:
    - `id` — короткий номер задания, как он показан на сайте («Номер: 45B944»); `guid` — внутренний идентификатор; `url` — ссылка на задание в банке;
    - `document_id` — ссылка на общий текст из `documents` (или `null`); `number_in_group` — номер задания внутри группы к тексту;
    - `hint` — инструкция («Выберите правильный ответ.» и т. п.);
    - `kes` — элемент(ы) содержания по кодификатору (строка или список); `answer_type` — тип ответа (выбор одного/нескольких, краткий, развернутый, соответствие);
    - `question_html` / `question_text` — условие в HTML (формулы в MathML) и в виде текста (формулы линеаризованы: `(5)/(9)`, `x^2`, `√(…)`);
    - `answer_html` / `answer_text` — варианты ответа или таблица для ответа;
    - `images` — картинки к заданию, `files` — вложения (mp3 для аудирования и изложения, zip/rar с файлами к заданиям по информатике). Пути указаны относительно `https://oge.fipi.ru/`, картинки лежат в `bank/media/` по тем же путям, вложения см. ниже.
- `bank/media/docs/<guid проекта>/…` — скачанные картинки (6431 файл, около 110 МБ). Вложения в репозиторий не включены: 561 файл общим объёмом более 15 ГБ (архивы к заданиям по информатике весят до 73 МБ каждый, аудио к аудированию и изложению — по 5–10 МБ). Пути к ним сохранены в поле `files`, скачать можно скриптом `tools/fetch_media.py` или напрямую по адресу `https://oge.fipi.ru/<путь>`.
- `bank/subjects.tsv` — GUID проектов банка по предметам.
- `bank/_stats.json` — сводная статистика.

Правильные ответы банк не публикует (проверка ответа выполняется на сервере ФИПИ), поэтому в выгрузке их нет. Ответы и критерии оценивания есть только в демоверсиях.

## Воспроизведение

```bash
cd fipi-oge/tools
./download_demos.sh 2027 2026        # демоверсии (curl, python3, poppler-utils)
python3 scrape_bank.py               # страницы банка -> raw/<код>/page_NNN.html
python3 parse_bank.py                # raw -> out/<код>.json
python3 fetch_media.py               # картинки и вложения -> images/ (в репозитории: bank/media/)
```

`oge.fipi.ru` отдаёт сертификат без промежуточного GlobalSign GCC R3 DV TLS CA 2020, поэтому скрипты ожидают файл `ca-with-gs.pem` — системный CA-бандл с добавленным промежуточным сертификатом (`https://secure.globalsign.com/cacert/gsgccr3dvtlsca2020.crt`).
